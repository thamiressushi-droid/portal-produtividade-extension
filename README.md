# portal-produtividade-extension
Plugin do navegador

Os intervalos de navegação são registrados como ativos enquanto houver
interação recente do usuário (mouse, teclado, rolagem ou clique). Após 5 minutos
consecutivos sem interação, o intervalo passa a ser registrado como inativo; uma
nova interação inicia outro intervalo ativo. O limite também é aplicado quando
o alarme é processado depois de uma suspensão do computador. Uma sessão
pendente é recuperada sem contabilizar o período em que o navegador esteve
fechado.

# portal-produtividade-extension
Plugin do navegador

As sessões de navegação são encerradas após 5 minutos sem interação do usuário
(mouse, teclado, rolagem ou clique). Cada intervalo sem interação é limitado a
esse prazo, inclusive quando o alarme é processado depois de uma suspensão do
computador. O bloqueio da estação encerra a sessão, e uma sessão pendente é
recuperada sem contabilizar o período em que o navegador esteve fechado.
